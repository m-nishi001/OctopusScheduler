# @octopus/table-io

表(景品・クイズ・メンバー・アセット・イベント・画面設定)の CSV / ZIP の一括書き出し・取込の共通部品。

- 列は `Header`(`key` / `label` / `aliases` / `required` / `media`)で定義する。見出しは `label` か `aliases` に一致する必要があり、使えなくなった古い見出しがあると、黙って無視せずエラーにする。
- 素材の列(`media: true`)には素材のファイル名を書く。中身は、CSV と一緒に選んだフォルダ(または ZIP の `media/`)から、名前と同じファイルを探す。
- 取込は先にプレビューを作る(行ごとに 追加 / 更新 / 変更なし / 削除 / エラー)。エラーの行が1つでもあれば取り込めない。
- 「置き換え」を選んだときだけ、ファイルに無い行を削除する。
- 画面側は `@octopus/ui-kit` の `TableIoToolbar` / `TableImportDialog` につなぐ。
