# ジャックポッド大会 Webアプリ設計書

## 1. アプリ概要
- 10人以上が参加し、抽選ゲームを楽しむWebアプリ。
- 若者向け・近未来的・パステルカラー基調のデザイン。
- 2D/3Dグラフィックを活用し、盛り上がる演出。

## 2. 画面構成
- ホーム画面
- オープニング画面
- 説明画面
- デモ抽選画面
- 本抽選画面
- 最終結果画面
- 管理画面

## 3. 画面遷移
1. ホーム画面
   - 「2025年度 ジャックポッド大会！」表示
   - アセットダウンロード（プログレスバー）
   - 「スタート」ボタンでオープニング画面へ
   - 「管理画面」ボタンで管理画面へ
2. オープニング画面
   - BGM/動画/テキスト（スクロール・フェード表示）
   - 全コンテンツ表示後、説明画面へ
3. 説明画面
   - オープニング同様、Enterキーで次コンテンツ表示
   - 全表示後、デモ抽選画面へ
4. デモ抽選画面
   - 1回だけ抽選デモ
   - 終了後「本抽選画面」へ
5. 本抽選画面
   - メンバー抽選→Enterで景品抽選
   - 演出・ルーレット等
   - 景品数半分時はモーダル表示
   - 景品0で最終結果画面へ
6. 最終結果画面
   - 抽選結果リスト（スクロール/BGM）
   - 最高/最低ランク当選者を強調表示
   - 終了後ホーム画面へ
7. 管理画面
    - メンバー・景品・画面設定等の管理
       - 景品管理：景品名・画像・ランク（1-10整数値）を登録可能
       - 景品画像はIndexedDBに保存、リストでサムネイル表示
       - ランクは入力＋ドロップダウン選択（コンボボックス）
       - ランクでソート表示可能
    - ホーム画面へ戻るボタン

## 4. アーキテクチャ設計
- フロントエンド: Vue.js + TypeScript
- DI: tsyringe
- ルーティング: vue-router
- データ保存: indexedDb
- デザイン: パステルカラー、2D/3D演出
- ドメイン駆動設計（DDD）


## 5. データ構造（最新実装）
 メンバー: id, name, photo（画像DataURL）
 景品: id, name, rank（1-10の整数値）, image（画像DataURL）
   - ScreenContent: id, screen（画面キー）, type（'bgm' | 'video' | 'text'）, value（ファイル名またはHTML）

## 6. その他
- 画面遷移はEnterキーで制御
- アセットは初回ホーム画面でDL
- 管理画面は仮設置（後で削除可）

## 7. 画面ごとの主要機能
### ホーム画面
- 大会タイトル表示
- アセット（音源・画像・動画等）ダウンロード＆プログレスバー
- 「スタート」ボタンで実行画面開始
- 「管理画面」ボタンで管理画面へ遷移

### オープニング画面
- BGM/動画/テキストの再生・表示（複数コンテンツ対応）
- テキスト表示方法（スクロール・フェードイン/アウト）
- 表示完了後、説明画面へ遷移

### 説明画面
- オープニング同様のコンテンツ表示
- Enterキーで次コンテンツ表示
- 全表示後、デモ抽選画面へ遷移
