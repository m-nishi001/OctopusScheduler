# 5. 困ったときのQ&A・用語集 {#faq}

<p class="lead"><span>この章でできること</span>よくあるトラブルの対処と、用語の意味がわかります。</p>

<dl class="qa">
<dt>参加者の画面が「接続中」にならない</dt>
<dd>イベントが「ポータルに公開」されているか、セッション一覧で確認してください。参加者側は再読み込みで直ることが多いです。</dd>
<dt>「ホストが不在です」と出る</dt>
<dd>会場PCで、セッション一覧の「ホストとして開く」を押してください。</dd>
<dt>顔写真が出ない(頭文字だけになる)</dt>
<dd>設定の「メンバー」(共通の名簿)で、その人に写真が設定されているかを確認してください。写真は名簿に保存されるので、会場PCがどのパソコンでも同じ写真が出ます。写真がない人は、頭文字のアイコンで表示されます。</dd>
<dt>QRコードをなくした・使えない</dt>
<dd>設定→メンバーで「QR再発行」を押し、印刷し直してください。以前のQRは使えなくなります。</dd>
<dt>クイズの正解が違っていた</dt>
<dd>クイズの編集で「回答（正解）」を直して保存します。</dd>
<dt>画面を変更したのに反映されない</dt>
<dd>画面設定は「保存」を押して初めて反映されます。</dd>
<dt>音楽を再生したのに、会場で音が出ない</dt>
<dd>会場PCの画面に「音を出すには、この画面を一度クリックしてください」と出ていないか確認し、出ていれば会場PCの画面を一度クリックします。それでも出ないときは、会場PCの音量と出力先を確認してください。</dd>
<dt>スクリーンに出したものが消えない・音楽が止まらない</dt>
<dd>スクリーンの画像・動画は、「消す」を押すまで出たままです。音楽は「停止」または「すべて停止」で止めます。「消す」では音楽は止まりません。</dd>
</dl>

### 用語集 {#glossary}

<dl class="qa">
<dt>セッション</dt>
<dd>1回のイベント(1つの会)のこと。</dd>
<dt>ホスト</dt>
<dd>会場のプロジェクターに映す画面。</dd>
<dt>操作画面(コンソール)</dt>
<dd>司会者が手元で進行する画面。</dd>
<dt>ポータル</dt>
<dd>参加者がスマホで見る画面。</dd>
<dt>受付QR</dt>
<dd>参加者がログインするためのQRコード。</dd>
<dt>エントリー</dt>
<dd>参加者が「エントリーする」を押すこと。</dd>
<dt>確変</dt>
<dd>運がよいと続けて当選できる演出。「確変対応あり」の景品だけが対象で、確変の回は対応ありの景品の数と同じです。</dd>
<dt>アセット</dt>
<dd>画像・動画・音声などの素材。</dd>
<dt>スクリーン</dt>
<dd>会場のプロジェクターに映る画面。画像・動画・スライドショーは、手元の操作画面から映して、「消す」で戻します。</dd>
</dl>
