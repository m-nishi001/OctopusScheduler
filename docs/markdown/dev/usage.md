# 使い方（設定画面 → 実行画面）

> **要点**
> - 設定画面で「アセット → イベント」の順に登録する
> - 投影用の実行画面（`/execute`）を別タブで開いておく
> - あとは設定画面のイベント一覧の「実行」を押すだけ
> - 画面ごとの案内は、設定画面右上の「ヘルプ」にある

## 基本の流れ

1. 設定画面で **アセット**（画像・動画・音声など）を登録する
2. **イベント**（何を流すか）を作る
3. ホームの「実行画面へ」、または設定画面ヘッダーの「実行画面を開く」で、投影用の `/execute` を別タブ／別ウィンドウで開く
4. 設定画面のイベント一覧で、動かしたいイベントを選んで「実行」を押す

## 一括の書き出し・取り込み(CSV / ZIP)

設定の「アセット」「イベント」「メンバー」タブは、上のボタンから CSV(「素材も含める(ZIP)」なら素材つきの ZIP)で書き出し・取り込みできます。取り込みの前にプレビューで行ごとの結果(追加・更新・変更なし・エラー)を確認でき、エラー行が1つでもあると取り込めません。使えなくなった古い見出しは、黙って無視せずエラーになります。

- アセット: 列は「名前」「フォルダ」(フォルダは1階層だけ)。素材の中身は、一緒に選んだフォルダ(または ZIP の `media/`)から、名前と同じファイルを探す。
- イベント: 列は ID・種別・開始・終了・素材・表示・フォルダ・切替秒・切替効果・フェードアウト秒・遷移先URL。取り込みは、ファイルに無いイベントを削除する置き換え。スライドショーは「フォルダ」列で素材のフォルダを指す。
- メンバー(名簿): 列は ID・名前・写真・管理者(管理者の列は設定>メンバーのCSVだけ)。

## 予定イベントの種類

設定画面の「イベント」タブで作る予定イベントは、次の3種類です。

| 種類 | 開始で | 終了で |
| --- | --- | --- |
| 音楽 | 曲を再生する | 指定の秒数でフェードアウトして止める |
| スクリーン | 画像・動画・スライドショーを映す | スクリーンを消す(ホスト画面に戻る) |
| 画面遷移 | 指定のパスへ移る | なにもしない |

以前の版にあった「音楽再生」「音楽停止」「コンテンツ表示」「スライドショー」のイベントは、読み込み時に捨てられます(移し替えはしません)。HTML コンテンツも無くなりました。必要なら、作り直してください。

## 当日に手元から音楽・スクリーンを出す

セッションの操作画面(スマホ)の「音楽・スクリーン」の欄から、ホスト(会場PC)に指示を送ります。予定イベントを作らずに、その場で出せます。

- 音楽: 曲ごとの「再生」「停止」と「すべて停止」。音楽は、停止の指示があるまで鳴り続けます。
- スクリーン: 画像・動画の「表示」、フォルダを選ぶか名前を入力するスライドショー、「消す」。出したものは「消す」まで出たままで、「消す」はホスト画面(ロビー)に戻します。音楽は止めません。
- 会場PCの音声: ブラウザの自動再生の制限で、画面を一度もクリックしていないと音が出ないことがあります。そのときは会場PCの画面に案内が出るので、一度クリックしてください。

## クイズ進行のキー

クイズの各画面では `Enter` で次の画面に進みます。文字入力欄にフォーカスがあるときは効きません。

## 会場の複数端末で進行する

投影 PC（ホスト）・手元の端末（管理）・参加者のスマホを結ぶ場合は、`/sessions` でセッションを作ります。詳しくは [session-hub.md](session-hub.md) を参照してください。ログインが必要な画面は [authentication.md](authentication.md) にまとめています。
