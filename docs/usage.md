# 使い方（設定画面 → 実行画面）

> **要点**
> - 設定画面で「アセット → イベント → ショートカット」の順に登録する
> - 投影用の実行画面（`/execute`）を **先に別タブで開いておく**。開いていないと何も映らない
> - あとは設定画面やクイズ画面でキーを押すだけ
> - 画面ごとの案内は、設定画面右上の「ヘルプ」にある

## 基本の流れ

1. 設定画面で **アセット**（画像・動画・音声など）を登録する
2. **イベント**（何を流すか）を作る
3. **ショートカット** でキーに割り当てる
4. ホームの「実行画面へ」、または設定画面ヘッダーの「実行画面を開く」で、投影用の `/execute` を別タブ／別ウィンドウで開く
5. 設定画面やクイズ画面でキーを押すと、実行画面に反映される

キー操作は BroadcastChannel で実行画面へ送られます。そのため、実行画面が開いていないと何も表示されません。

## ショートカットの仕様

| 項目 | 仕様 |
| --- | --- |
| キー数 | 最大 3 キー（押した順を区別） |
| 入力のリセット | 1.5 秒入力が途絶えるとリセット |
| 前方一致 | 長いショートカットと前方一致する場合は 0.4 秒待って確定 |
| `Esc` | 予約済み。全音声を停止 |
| 文字入力中 | 入力欄にフォーカスがあるときは無効 |
| クイズ進行 | 各画面で `Enter` が次の画面へ |

## 会場の複数端末で進行する

投影 PC（ホスト）・手元の端末（管理）・参加者のスマホを結ぶ場合は、`/sessions` でセッションを作ります。詳しくは [session-hub.md](session-hub.md) を参照してください。ログインが必要な画面は [authentication.md](authentication.md) にまとめています。
