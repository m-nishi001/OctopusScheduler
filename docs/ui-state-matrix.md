# 画面 × 状態マトリクス

各画面の「いま何が起きているか」と「主ボタンを押すと何が起きるか」を1行で言えることを、設計の基準にする。
1行で言えない操作は、UI を見直す対象。各行はテスト(単体: U / e2e: E)に紐付ける。

| 画面 | 状態 | 画面が示すこと | 主操作で起きること | テスト |
|---|---|---|---|---|
| クイズ結果(ホスト) | 順位発表中 | 順位を下から順に表示 | (操作なし) | E: participant-quiz |
| クイズ結果(ホスト) | 発表後・当選者あり | 1位を祝う | 次へ → 景品を表示 | U/E: PR1 |
| クイズ結果(ホスト) | 発表後・当選者なし | 「正解者なし」 | 次へ → ロビーに戻る | U/E: PR1 |
| クイズ結果(ホスト) | 景品表示中 | 当選者名と景品 | 次へ → ロビーに戻る(管理画面には出ない) | U/E: PR1 |
| ジャックポット(参加者) | 抽選中 | 結果だけ表示。停止ボタンは出ない | (操作なし) | U/E: PR1 |
| ジャックポット 景品抽選 | ルーレット/スロット 開始〜回転〜停止 | 回転中は絵が動き、停止後は止まる | 次へ → 開始 / 止める → 停止 | E: PR1(スクリーンショット列) |

PR ごとに、扱った画面の行をここへ追加する(コントロール画面・ポータル・セッションなど)。

## 動きの確認(スクリーンショット列)

`e2e/ui/helpers/motion.ts` が一定間隔で撮影し、フレームの変化で「動いている/止まっている」を判定する。
カウントダウンは数値の減少も併せて確認する。撮影画像は Playwright の添付(CI では artifact)と `E2E_SHOTS` に残る。

## 並列度

E2E は 1 つの wrangler(= 1 つの DB)を共有し、参加者ポータルに公開できるセッションは 1 つだけのため、
同じ wrangler 内ではテストを並列化しない(`workers: 1`)。並列度は CI のシャード数(各シャードが別の wrangler を起動)で稼ぐ。
