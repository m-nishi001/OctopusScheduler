# 画面 × 状態マトリクス

各画面の「いま何が起きているか」と「主ボタンを押すと何が起きるか」を1行で言えることを、設計の基準にする。
1行で言えない操作は、UI を見直す対象。各行はテスト(単体: U / e2e: E)に紐付ける。

| 画面 | 状態 | 画面が示すこと | 主操作で起きること | テスト |
|---|---|---|---|---|
| クイズ結果(ホスト) | 順位発表中 | 順位を下から順に表示 | (操作なし) | E: participant-quiz |
| クイズ結果(ホスト) | 発表後・当選者あり | 1位を祝う | 次へ → 景品を表示 | U: host-agent.spec / E: participant-quiz |
| クイズ結果(ホスト) | 発表後・当選者なし | 「正解者なし」 | 次へ → ロビーに戻る | U: host-agent.spec / E: participant-quiz |
| クイズ結果(ホスト) | 景品表示中 | 当選者名と景品 | 次へ → ロビーに戻る(管理画面には出ない) | U: host-agent.spec / E: participant-quiz |
| ジャックポット(参加者) | メンバー抽選中 | 結果だけ表示。停止ボタンは出ない(管理端末だけが止める) | (操作なし) | U: use-jackpot-host / E: participant-jackpot |
| ジャックポット(参加者) | 景品抽選・止められる場面 | 「ルーレットを止める」が出る | 押すと止まる | U/E: participant-jackpot |
| ジャックポット 景品抽選 | ルーレット/スロット 開始〜回転〜停止 | 回転中は絵が動き、止めると当選が発表される | 次へ → 開始 / 止める → 停止 | U: slot-animation.spec / E: jackpot-prize-draw(スクリーンショット列) |

## コントロール画面(主ボタン)

主ボタンは常に1つ。文言と予告は `apps/app-scheduler/.../session/console-guidance.ts` が状態から導き、`console-guidance.spec.ts` で全状態を固定している。

| 状態 | 「いま」 | 主ボタン → 押すと起きること |
|---|---|---|
| ホスト不在 | ホストの画面が開かれていません | (無し。「この端末をホストにする」を案内) |
| ロビー / エントリー画面 | 待機中 | (無し。「始める」カードから開始) |
| クイズ イントロ | イントロ表示中 | 次へ → QRコードを映す |
| クイズ QR | QRコード表示中 | 次へ → 問題を映し、回答受付を始める |
| クイズ 出題・回答受付中 | 回答受付中(回答N人) | 受付を締め切る → 回答を締め切る |
| クイズ 出題・受付終了 | 受付終了 | 次へ → 正解を発表 |
| クイズ 正解発表 | 正解発表中 | 次へ → 結果を発表 |
| クイズ 結果 | 結果発表中 | 次へ → 当選者がいれば景品、いなければロビー |
| ジャックポット オープニング/説明/結果 | 各画面の表示中 | 説明へ / 抽選を始める / エンディングへ → 画面を切り替える |
| ジャックポット 抽選・止められる | メンバー/景品抽選 | 止める → ルーレットを止めて結果を決める |
| ジャックポット 抽選・それ以外 | メンバー/景品抽選(当選者・景品) | 次へ → 抽選を進める |

「始める」カード(クイズ / ジャックポット / エントリー受付)は、イベントが未開催なら開催し、対象の画面まで一度に進める。セッション一覧の「今すぐイベントを開催する」は、セッション作成・ポータル公開・操作画面への移動を一度に行う。

PR ごとに、扱った画面の行をここへ追加する(コントロール画面・ポータル・セッションなど)。

## 動きの確認(スクリーンショット列)

`e2e/ui/helpers/motion.ts` が一定間隔で撮影し、フレームの変化で「動いている/止まっている」を判定する。
カウントダウンは数値の減少も併せて確認する。撮影画像は Playwright の添付(CI では artifact)と `E2E_SHOTS` に残る。

## 並列度

E2E は 1 つの wrangler(= 1 つの DB)を共有し、参加者ポータルに公開できるセッションは 1 つだけのため、
同じ wrangler 内ではテストを並列化しない(`workers: 1`)。並列度は CI のシャード数(各シャードが別の wrangler を起動)で稼ぐ。
